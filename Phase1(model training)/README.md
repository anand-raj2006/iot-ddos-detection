Developed a cybersecurity-focused project aimed at detecting and mitigating Distributed Denial-of-Service (DDoS) attacks in IoT environments. Leveraging datasets like CICIDS2023, the system applies machine learning and deep learning models (including CNNs and Random Forest) for efficient anomaly detection and traffic classification. The project emphasizes feature selection, real-time threat detection, and scalable deployment for Industrial IoT (IIoT) systems.
